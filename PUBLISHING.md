## GitHub Pages

1. Create the public repository `electronic-customs-records-auditor-demo`.
2. Push this repository package to `main`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions** if GitHub has not already enabled it from the workflow.
5. The included `Deploy portfolio demo to GitHub Pages` workflow will publish the static case-study page.
6. Confirm the video, screenshots and sample report load correctly.
7. Add the Pages URL to the repository **Website** field.

Expected Pages URL:

```text
https://yospadilla.github.io/electronic-customs-records-auditor-demo/
```

## Before making it public

- Confirm the final MP4 is the intended edited version.
- Confirm the background music is licensed/royalty-free or otherwise cleared for public use.
- Confirm all records shown are synthetic.
- Confirm no `output/`, local diagnostic logs, credentials or company data are committed.
- Confirm the sample XLSX opens without recovery warnings.
- Confirm the GitHub Pages video plays in Chrome/Edge and on mobile.
